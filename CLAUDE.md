# UniFi workspace — правила роботи

Цей workspace використовується для підключення до UniFi (Ubiquiti) dashboard через API.

## ⚠️ ГОЛОВНЕ ПРАВИЛО

**НІЧОГО НЕ ЗМІНЮВАТИ БЕЗ ЯВНОГО ДОЗВОЛУ КОРИСТУВАЧА.**

- Дозволено без запиту: лише читання (GET-запити) — перегляд хостів, сайтів, пристроїв, клієнтів, статусів, метрик.
- Будь-яка зміна (POST / PUT / PATCH / DELETE: перезавантаження пристроїв, зміна налаштувань,
  блокування клієнтів, оновлення прошивки, створення/видалення чогось тощо) — **тільки після того,
  як користувач явно підтвердив саме цю дію в поточній розмові**.
- Перед запитом на дозвіл описати: що саме буде змінено, на якому пристрої/сайті, і які можливі наслідки.
- Дозвіл на одну дію не поширюється на інші дії.
- `unifi.py` блокує всі не-GET запити, якщо не передано прапорець `--allow-write`. Використовувати його
  тільки після підтвердження користувача.

## Мова

Спілкуватися з користувачем українською.

## Налаштування

1. Скопіювати `.env.example` → `.env` і вписати API ключ (`.env` у `.gitignore`, не комітити).
2. Ключ для Site Manager (cloud): unifi.ui.com → Settings → API → Create API Key.
3. Ключ для локального контролера (Network Integration API): UniFi Network → Settings → Control Plane → Integrations.

## Використання

```bash
python3 unifi.py GET /v1/hosts            # cloud: список консолей
python3 unifi.py GET /v1/sites            # cloud: сайти
python3 unifi.py GET /v1/devices          # cloud: пристрої
python3 unifi.py --local GET /v1/sites    # локальний контролер (Integration API)
```

Документація API: https://developer.ui.com
